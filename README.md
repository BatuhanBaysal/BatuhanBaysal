### 💼 Featured Projects

**[Chess Platform](https://github.com/BatuhanBaysal/chess-platform)** — *my most ambitious project to date, still under active development*
A real-time multiplayer chess platform with a FIDE rule engine I wrote entirely myself (no third-party chess API) and an AI opponent via the Stockfish engine (UCI protocol, sidecar pattern). Beyond the code, this is the project where I stopped treating side projects as throwaway exercises: it's governed with GitHub Issues, Milestones, a Kanban board, PR templates, semantic version tags, and GitHub Releases, all validated through a CI/CD pipeline — a SonarQube A-grade quality gate with 91.5% test coverage backs it up. **236 commits and counting.**

**[Secure Banking Core](https://github.com/BatuhanBaysal/secure-banking-core)**
A modular monolith banking backend — and the project where I learned to take feedback from my own code. It started with a custom JWT implementation; I later migrated it to **Keycloak** for proper IAM/RBAC, and refactored a SonarQube-flagged 4-hour technical debt down to zero, landing an **A-rating with 0 bugs and 0 code smells**. Also includes Resilience4j fault tolerance, RabbitMQ messaging, Liquibase migrations, and full Docker/Kubernetes manifests. **187 commits.**

**[Spring Cloud Observable Microservices](https://github.com/BatuhanBaysal/spring-cloud-observable-microservices)**
An Account/Product microservice pair with Eureka service discovery, a central API Gateway, Redis-backed instant JWT blacklisting on logout, and full distributed tracing via Zipkin, Prometheus, and Grafana. This is where I first learned to think in distributed systems instead of single-app terms.
